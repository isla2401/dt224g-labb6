# DT224G - Laboration 6
## Receptsökaren :fried_egg:

Syftet med denna uppgift var att öva på asynkron programmering och hämtning av data från externa källor. Receptsökaren använder *Fetch API* för att hämta data asynkront från [Dummy JSON:s API för recept](https://dummyjson.com/docs/recipes). Om ett recept hittas så visas det på sidan, annars visas ett felmeddelande.
